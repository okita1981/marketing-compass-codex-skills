# Changelog

All notable changes to the `thinking-staircase` Claude Code plugin are documented here. Versions follow [Semantic Versioning](https://semver.org).

## 1.0.0 — 2026-08-25

Initial release. Split out from the `marketing-compass` plugin (previously `marketing-compass:thinking-staircase` in that plugin's 1.0.0–1.x releases) into its own package, since Thinking Staircase is a general-purpose thinking-navigation skill and not specific to Marketing Compass. Bundles:

- `thinking-staircase:thinking-staircase`

The skill's `SKILL.md` and `references/` are byte-identical copies of the canonical source at `skills/thinking-staircase/` in the parent repository. No judgment logic, definitions, or Guardrails differ from the GPT/Codex version.
